# Application icon

The planner's own mark, delivered by Shade-Tech for request R31 and accepted by the
owner on 2026-10-30. It is not game art.

- `../application.ico`: the window, taskbar and executable icon, with 16, 24, 32, 48,
  64 and 256 px frames. SHA-256 `6e040e548e6de7c9fe4924c0b17f49f1fa731f8f2082e5a31c43d11afe1d57b7`.
- `master.png`: the 1024 px master. SHA-256 `a8b1de38347bba41ee24e91acb6c679db32d6b45a46ce713a0a21f7d9b74ff2f`.
- `mark.svg`, `record.json`, `export.json`: the source geometry, the source record
  (authorship and recipe) and the export receipt, as delivered.
- `visual-acceptance.json`: the owner's acceptance receipt.
- `LICENSE.txt`: MIT, copyright 2026 Shade-Tech contributors. It ships in the release
  as `licenses/shadetech-artwork-MIT.txt`, which also covers the pack's original slot
  images (the same notice).

The files are copied unchanged from Shade-Tech's
`results/r31-application-icon-v1/` (see its `APPLICATION_ICON_HANDOFF.md`). To
change the icon, ask Shade-Tech for a new delivery rather than editing these.
